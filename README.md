# QuickMedia

媒体服务器：高性能 + 易扩展。主流多媒体协议全内建，受授权/专有协议以进程外网关方式接入。

## 当前状态

架构设计已定稿并评审通过，语言决策为 **Go 1.24+**（单二进制）。代码实现尚未开始，M0（1 周骨架 PoC）为下一阶段起点。

## 文档

- `docs/quickmedia-architecture.md` — 架构设计 v0.2（2026-09-19）。分层与模块边界、数据面/控制面分离、Unit 零拷贝模型、线程与并发模型、三类插件契约、进程外 gateway、协议分级 P0/P1/P2、集群三阶段路线、可量化验收口径与里程碑 M0–M4。后续所有开发 issue 以此文档为输入，其中接口定义在 M0 阶段冻结。
- `attachments/YEJ-178-report.md` — ZLMediaKit 与 MediaMTX 对照调研报告，是本架构设计的调研输入。
